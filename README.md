# Lista 03 - Exercício 04

Projeto desenvolvido utilizando HTML, CSS e JavaScript.

## Descrição

O programa calcula a área de um círculo a partir do valor do raio informado pelo usuário.

A fórmula utilizada é:

Área = π × raio²

Para o valor de π, foi utilizado o `Math.PI` do JavaScript.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como utilizar

1. Digite o valor do raio do círculo.
2. Clique no botão "Calcular".
3. O resultado da área será exibido na tela.
